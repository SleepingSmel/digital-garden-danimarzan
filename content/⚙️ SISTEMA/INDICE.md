## 🔄 FLUJO DE CREACIÓN DE UN VÍDEO

```
1. 📚 BANCOS/IDEAS → Elegir tema
2. ⚙️ SISTEMA/GUÍA-DE-CONTENIDO → Estructura + leyes
3. ⚙️ SISTEMA/MARCA → Tono + identidad
4. 📚 BANCOS/FILOSOFIA → Citas si necesitas profundidad
5. GRABAR → ⏎ 8-10 min
6. SUBIR → Mover a ✅ GRABADOS/
```

---

## 📏 REGLAS DEL VAULT

1. **1 vídeo por semana. Sin excusas.**
2. INBOX se procesa semanalmente (nunca más de 5 archivos acumulados)
3. SEMILLAS máximo 10 archivos
4. La investigación se mueve a `📚 BANCOS/` cuando se convierte en material reutilizable
5. Nada se elimina: se mueve a `ToDelete/` o `🗄️ ARCHIVO/`
6. Este índice se actualiza cada vez que se crea una nota importante o cambia la estructura
