# 🏷️ Sistema de Etiquetas del Vault

> **Principio:** Pocos tags, bien organizados, alto valor. Cada tag debe responder a la pregunta: *"¿Cómo encuentro esto cuando lo necesito?"*

---

## 🔴 Tags de contenido principal (nicho)

Estos definen EL TEMA de la nota:

| Tag | Qué incluye | Ejemplo |
|-----|-------------|---------|
| `#copywriting` | Técnicas de escritura persuasiva, emails, storytelling | 9 técnicas de Isra Bravo |
| `#marca-personal` | Estrategia de marca, visibilidad, posicionamiento | Leyes de Jordi Segués |
| `#motivación` | Contenido motivacional, mentalidad, transformación | La Triple D |
| `#enemigo-común` | Framework del enemigo en comunicación | Nike vs pereza |
| `#outreach` | Prospección B2B, emails fríos, ventas | Secuencia de outreach |
| `#youtube` | Estrategia de canal, formato, producción | Análisis de vídeo |
| `#ventas` | Cierre, objeciones, persuasión comercial | Leyes de venta |

## 🟡 Tags de framework/autor

Estos definen DE DÓNDE viene la información:

| Tag | Autor/Referencia |
|-----|------------------|
| `#isra-bravo` | Técnicas de email y copywriting |
| `#jordi-segués` | Leyes de contenido y marca personal |
| `#storytelling` | Técnicas narrativas (cualquier fuente) |

## 🟢 Tags de estado/formato

Estos definen EN QUÉ ESTÁ el contenido:

| Tag | Significado |
|-----|-------------|
| `#script` | Guión listo para producir (aprueba de concepto OK) |
| `#crudo` | Material sin procesar (transcripciones, notas sueltas) |
| `#guion` | Guión en desarrollo (cualquier etapa) |
| `#review` | Análisis/revisión de contenido existente |
| `#batallas-personales` | Contenido motivacional basado en experiencia propia |
| `#hooks` | Frases gancho, títulos, aperturas potentes |
| `#cierres` | Llamadas a la acción, cierres de emails/vídeos |

## 🔵 Tags de negocio

Para notas relacionadas con TU negocio de freelancing:

| Tag | Qué incluye |
|-----|-------------|
| `#buyer-persona` | Perfil de cliente ideal |
| `#precios` | Tarifas, ofertas, propuestas |
| `#servicios` | Descripción de servicios ofrecidos |
| `#caso-de-estudio` | Resultados reales de clientes |

## ⚫ Tags de sistema (no son contenido)

Solo para notas de configuración/mantenimiento:

| Tag | Uso |
|-----|-----|
| `#sistema` | Notas técnicas del vault, scripts, config |
| `#inbox` | Captura rápida, por procesar |
| `#borrador` | Nota en estado inicial |

---

## ❌ Tags que NO usar

- `#nota`, `#info`, `#general`, `#misc` — demasiado genéricos
- `#bueno`, `#importante`, `#top` — subjetivos, no filtrables
- `#2026`, `#junio` — temporales, pierden sentido
- Tags con emojis como nombre — difíciles de buscar

---

## 🧠 Cómo usar esta convención

1. **Máximo 3-4 tags por nota** — si necesitas más, probablemente la nota debe dividirse
2. **Siempre 1 tag de contenido principal** — ¿de qué trata esto?
3. **Opcional 1 de framework** — ¿de dónde viene?
4. **Opcional 1 de estado/formato** — ¿en qué estado está?
5. **Usa el buscador del vault** — `tag:#isra-bravo` muestra todo lo de Isra Bravo
